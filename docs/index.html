PDF TRANSLATOR
LAYOUT-PRESERVING TRANSLATION

PDF의 형식을 유지하며
문서만 번역합니다.

원본의 그림·표·수식을 보존하고, 번역문을 같은 영역에 맞춰 다시 배치합니다.

Supabase 설정이 필요합니다. docs/config.js에 Supabase URL과 publishable key를 입력하세요.
처리 중

PDF를 분석하고 있습니다.

완료

번역 PDF가 준비되었습니다.

01

수식 보존

수학 영역은 번역하지 않고 원본 페이지의 표현을 유지합니다.

02

겹침 방지

번역문이 원래 텍스트 영역을 벗어나지 않도록 자동으로 맞춥니다.

03

Supabase 저장

원본 PDF, 번역 결과와 작업 상태를 Supabase에 저장합니다.

1차 데모 · 텍스트 선택이 가능한 PDF를 대상으로 합니다. 처리 시작까지 몇 분 걸릴 수 있습니다.
