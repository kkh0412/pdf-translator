PDF TRANSLATOR
STYLE-PRESERVING LATEX TRANSLATION

PDF의 스타일을 살려
번역본을 다시 조판합니다.

원본의 제목 계층·글꼴 분위기·목록·그림·수식을 분석하고, 번역문 전체를 LaTeX로 자연스럽게 다시 조판합니다.

Supabase 설정이 필요합니다. docs/config.js에 Supabase URL과 publishable key를 입력하세요.
처리 중

PDF를 분석하고 있습니다.

완료

번역 PDF가 준비되었습니다.

01

수식 보존

수학 영역은 번역하지 않고 원본 페이지의 표현을 유지합니다.

02

책다운 조판

본문은 명조 계열의 출판용 글꼴을 사용하고, 제목·소제목·인용문·목록의 위계를 LaTeX로 재현합니다.

03

자연스러운 재배치

원래 좌표에 억지로 끼워 넣지 않고 내용 길이에 맞춰 문단과 그림을 자연스럽게 재배치합니다.

1차 데모 · 텍스트 선택이 가능한 PDF를 대상으로 합니다. 처리 시작까지 몇 분 걸릴 수 있습니다.
